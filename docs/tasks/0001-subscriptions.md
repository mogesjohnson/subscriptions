# 0001: subscriptions PWA

Status: in progress. Owner: Moges Johnson. Agent: grok-bot.

## Goal

A bare-minimum static PWA for Moges's Android phone (Chrome "Add to Home screen") that tracks
subscriptions offline. No backend, login, bank connection or analytics.

## Acceptance criteria

- Add, edit and delete a subscription: name, price (2 decimals), cycle (monthly or yearly), next renewal date; inputs validated.
- List sorted by next renewal, soonest first, with days until renewal; past-due rows highlighted.
- Monthly total (yearly / 12) and yearly total (monthly x 12) in USD via Intl.NumberFormat.
- Data in localStorage under `subs.v1` with safe JSON parsing; `navigator.storage.persist()` requested once, guarded.
- manifest.webmanifest with 192/512 PNG icons generated by a script; `sw.js` caches the shell with relative paths.
- Mobile-first, dark-mode friendly, large tap targets. Served by GitHub Pages from main `/`.
